# 5.3 Review of RQ3 and H3

RQ3 was mainly addressed by the works presented in [Chapter 2](ch_2-introduction.md) and [Chapter 4](ch_4_introduction.md). The work in [Chapter 3](ch_3_introduction.md) includes the development of the Planner.js Typescript library, which demonstrates the possibility of implementing complex and decentralised route planning applications taking data directly form the Web. However, Planner.js was not and has not been used in real scenarios beyond academic testing.

Similarly to RQ1, the work done in the Velopark platform and in the RCC Web application, stand as evidence of modern and in-use decentralised applications that rely on semantic annotations to retrieve relevant data from the Web to support their own use cases. In the case of Velopark, the user-oriented application was built using the Angular framework and in the case of ERA the React framework, both popular and modern alternatives. Regarding development times, the majority of the time (~60%) in both scenarios, was spent on the creation of semantic data models instead of actual application development. These estimations are made from the type and distribution of tasks performed during the execution of both projects, where despite trying to follow a predefined methodological plan, discussion and revisiting of the data models design were recurrent and happened throughout the duration of the projects. Furthermore, the use of generic RDF libraries (e.g., based on the RDF-JS specification), reduce the coupling between the application and the ontology terms, which allowed for independent feature development. The work presented in both chapters shows that Linked Data technologies can be supported and use together with modern and developer-friendly Web application development frameworks. Also, the successful deployment and real use of both the Velopark platform and the ERA RCC Web application, confirm that decentralised Linked Data applications can be used in practice.

Based on this evidence, I move onto accepting H3 and to stating that Linked Data technologies do provide a sufficiently mature open-source tool ecosystem to support the timely development of modern and decentralised Web applications, that are usable in practice for real (transport) use cases.
