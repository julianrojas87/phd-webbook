# 5.5 Concluding remarks

The Semantic Web may not be achievable today as the utopic vision that was advertised from the beginning, however the foundations that were established in the pursuit of that dream are not all useless and are proving their worth when used for and within reasonable goals, as this dissertation tries to show. The current state of Linked Data technologies allows to show useful and real results, therefore making possible for mindsets to be changed. Slowly but steady, keep on building toward the Semantic Web dream.

To conclude this PhD, I would like to borrow one of the final statements form the [unfinished book of Aaron Swartz](https://upload.wikimedia.org/wikipedia/commons/3/3f/Aaron_Swartz_s_A_Programmable_Web_An_Unfinished_Work.pdf):

*"...the Semantic Web is based on [a] bet, a bet that giving the world tools to easily collaborate and communicate will lead to possibilities so wonderful we can scarcely even imagine them right now."*
