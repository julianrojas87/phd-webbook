# 1.5 Contributions

During the development of this PhD, I was able to make the following contributions that include open-source software libraries and applications, participation in multilateral research projects and invited talks:

* Invited [keynote talk](https://sem4tra2022.linkeddata.es/presentations/keynote.pdf) titled "*Building a KG for the European Railway Agency: The story*" for the 3rd Semantics for Transport Workshop at the SEMANTiCS conference. 2022.

* [Talk](https://op.europa.eu/en/web/endorse-2021/programme) "*The ERA Knowledge Graph: Raising data interoperability in the railway domain*" at the European Conference on Reference Data and Semantics - ENDORSE. 2021.

* [gtfs2lc](https://github.com/linkedconnections/gtfs2lc): Javascript Node.js CLI tool to transform GTFS data to RDF following the [Linked-GTFS](https://github.com/OpenTransport/linked-gtfs) and the [Linked Connections](http://semweb.mmlab.be/ns/linkedconnections) vocabularies.

* [gtfsrt2lc](https://github.com/linkedconnections/gtfsrt2lc): Javascript Node.js CLI tool to parse and transform GTFS-realtime data to RDF based on the Linked-GTFS and Linked Connections vocabularies.

* [Linked Connections Server](https://github.com/linkedconnections/linked-connections-server): Node.js Web server implementation to create and publish Linked Connection APIs from both static and realtime GTFS files.

* [ERA Vocabulary](https://data-interop.era.europa.eu/era-vocabulary/): RDF ontology for the European Agency for Railways (ERA) that describes the topological and physical characteristics of the European railway infrastructure.

* [Open Velopark Vocabulary](https://data.velopark.be/openvelopark/vocabulary): RDF ontology that describes physical properties of bicycle parking facilities.

* [Route Compatibility Check](https://github.com/julianrojas87/era-compatibility-check): React-based Web application that performs route compatibility checks over the European railway infrastructure.

* [era2osm](https://github.com/julianrojas87/era2osm): Typescript CLI application that extracts topological RDF data via pre-configured SPARQL queries and transforms it to the OpenStreetMap (OSM) XML syntax.

* [Planner.js](https://github.com/openplannerteam/planner.js): Typescript public transport route engine and library, supporting Earliest Arrival and Profile queries over Linked Connection interfaces and Bidirectional Dijkstra over OSM road networks published as routable tiles [@@Colpaert_ESWC_2019].

* [osm-rdf-mapper](https://github.com/julianrojas87/osm-rdf-mapper): Javascript CLI tool for transforming OSM protobuf files into RDF based on the <https://w3id.org/openstreetmap/terms#> vocabulary.

* [RMLMapper](https://github.com/RMLio/rmlmapper-java/pull/158): Contribution that added support for XPath v2 and v3 on the RMLMapper engine and optimised the processing of XML data sources.

* [ERA RML mappings](https://github.com/julianrojas87/era-data-mappings): Collection of YARRRML mapping files used to create the ERA knowledge graph.

* [Velopark Rich Snippets Generator](https://github.com/julianrojas87/velopark-rich-snippets-generator): Web application that enables the management and semantic annotation of bicycle parking facilities via forms and serialise the data using JSON-LD.

* [Linked Time Series Server](https://github.com/linkedtimeseries/timeseries-server): Node.js Web server to publish time series data using temporal fragmentation and produced derived aggregations based on the Multidimensional Interfaces vocabulary [@@Taelman_IWCL_2016].

* [tree-geocoder](https://github.com/julianrojas87/tree-geocoder): A Node.js CLI and library for geocoding based on GeoNames data and the TREE traversal approach.

* [OASIS](https://github.com/cef-oasis/): Participated and contributed to the OASIS (Open Applications for Semantically Interoperable Services) project. Together, Ghent and the region of Madrid initiated an innovative action to increase the accessibility of public services and public transport. They collaborated to publish Linked Open Data to prove that new technologies (such as the Semantic Web) can lead to economies of scale, such as the creation of cross-country applications.

* [HOBBIT](https://project-hobbit.eu/): Participated and contributed to the HOBBIT project. HOBBIT aimed at abolishing the barriers in the adoption and deployment of Big Linked Data by European companies, by means of open benchmarking reports that allow them to assess the fitness of existing solutions for their purposes.

* [OpenPlanner](https://openplanner.team/): Participated and contributed to the OpenPlanner project. The Open Planner Team wanted to empower anyone to build any kind of route planner, without having to invest in data integration.

* [Velopark](https://www.velopark.be/en/about): Participated and contributed to the Velopark project. Velopark is a digital platform that makes information about bike parks in Belgium accessible to all.

* [SmartWaterWay](https://www.imec-int.com/en/research-portfolio/smartwaterway): Participated and contributed to the SmartWaterWay project. SmartWaterWay aimed at offering a cost-efficient manner to automate small vessels used for urban logistics in cities with a dense network of small waterways.

* [BAS-X](https://www.victoris.be/projects/bas-x/): Participated and contributed to the BAS-X project. BAS-X aims to allow as many people (45+) as possible to spend a basic number of active hours per week outdoors through the 3 most popular activities: running, cycling and walking.

* [GreenMov](https://green-mov.eu/): Participated and contributed to the GreenMov project. Within the GreenMov project, effort was made to better describe mobility-related data sources and make them more accessible.

* [ERA-KG](https://www.era.europa.eu/library/era-knowledge-hub_en): Participating and contributing to the ERA-KG project. Bilateral collaboration with the ERA to create and evolve a semantic interoperability layer that integrates the different base registries maintained by the agency and support innovative services such as the Route Compatibility Check and Infrastructure Change Alert use cases.

* [SEMIC](https://joinup.ec.europa.eu/collection/semic-support-centre/welcome): Participating and contributing to the SEMIC initiative. SEMIC sets up pilots to showcase the value of new approaches and ecosystems (e.g. Linked Data Event Streams, Solid and Wikibase/Wikidata), which can be leveraged across public administrations to scale up their interoperability maturity (e.g. catalogue of services, base registries).
